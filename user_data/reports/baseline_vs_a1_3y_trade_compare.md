# Baseline vs A1 四次分批 三年对比

生成时间：2026-06-30

对比对象：

- Baseline：`DualTrendCombinedShortPullbackShapeV1Strategy`
- A1：`DualTrendCombinedShortPullbackShapePartialLadderA1FourStepLock876Roi50Strategy`

区间：

- `2023-06-18 -> 2026-05-08`
- 使用 `1h + 5m detail`

说明：

- 这里的 A1 指当前四次分批版本：
  - 分批 `50% / 25% / 12.5% / 12.5%`
  - 锁盈 `5% / 6% / 7% / 8%`
- 由于本地 5m 数据到 `2026-05-08` 更完整，本次三年对比采用这个可比区间。

## 总体结果

| 策略 | Trades | Profit | PF | MaxDD | Winrate |
|---|---:|---:|---:|---:|---:|
| Baseline | 280 | 178.48% / 1784.771 | 1.96 | 5.89% | 33.9% |
| A1 FourStep Lock876 | 262 | 90.58% / 905.757 | 2.01 | 7.85% | 48.5% |

结论：

- A1 明显提高了胜率：`33.9% -> 48.5%`
- PF 只小幅提高：`1.96 -> 2.01`
- 总收益显著下降：`178.48% -> 90.58%`
- MaxDD 反而扩大：`5.89% -> 7.85%`

所以三年样本下，A1 不是“更强的盈利版本”，而是“更高胜率、但压低总收益”的版本。

## 分批止盈到底帮了多少

A1 四次分批的阶段达成率：

| 阶段 | 达成数 | 占全部 A1 交易 |
|---|---:|---:|
| TP1 达成 | 47 | 17.9% |
| TP2 达成 | 16 | 6.1% |
| TP3 达成 | 8 | 3.1% |
| TP4 达成 | 2 | 0.8% |

只看 A1 的盈利单：

| 阶段 | 达成数 | 占 A1 盈利单 |
|---|---:|---:|
| TP1 达成 | 47 | 37.0% |
| TP2 达成 | 16 | 12.6% |
| TP3 达成 | 8 | 6.3% |
| TP4 达成 | 2 | 1.6% |

解释：

- 分批止盈确实触发了，但真正走到深层分批的交易很少
- 大多数盈利单并没有走完四档
- A1 的主要收益改善并不是来自“分批把大盈利越滚越大”，而更多来自“把一部分原本会亏的单子提前保护掉”

## 为什么理论上 ROI 10% 改成分批后，不一定利润更高

表面上看，Baseline 是 `ROI 10%`，A1 是分批，似乎应该让利润更高。

但实际不是这样，原因有三个：

1. A1 把 `minimal_roi` 提高到 `50%` 后，很多原来会在 `10%` 直接落袋的单子，不再自动落袋，而是继续暴露给后续回撤。
2. 新的锁盈止损会让不少单子在没有达到第一档分批前，就先被 `trailing_stop_loss` 带出去。
3. 持仓时间变长后，会改变槽位释放节奏，进而影响后续是否还能进别的高质量单。

这在样本里非常明显：

- 很多 Baseline 的大盈利单是 `roi` 退出
- 到了 A1，这些单子变成了 `trailing_stop_loss`
- 而且其中不少连第一次 `partial_exit` 都没有触发

## 最重要的结论

1. A1 相比 Baseline，最大的作用是“减亏”和“扭亏”，不是“放大已经盈利的趋势单”。
2. 三年样本下，A1 救回了很多亏损单，但削掉了更多高质量盈利单，所以总收益明显变差。
3. 四档分批本身能触发，但真正走到深层分批的比例不高，分批止盈对总收益的帮助有限。
4. 当前这版 A1 更像风格切换：从“低胜率、高弹性”切向“高胜率、低收益上限”。
5. 如果目标仍是主策略收益最大化，三年样本下应继续保留 Baseline 作为主线。
