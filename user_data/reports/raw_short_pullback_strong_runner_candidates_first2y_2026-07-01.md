# Raw short_pullback_restart 强单放行候选

日期: 2026-07-01

## 目标

基于前两年 `DualTrendRawStrategy` 的 `short_pullback_restart` 交易，验证当一笔空头单已经先触及 `+5%` 浮盈后，是否能用简单规则识别“值得继续放行冲 `+10%`”的强单。

本轮仍然是离线诊断，不修改策略。

## 输入样本

来源文件:

- [raw_short_pullback_touch5_diagnosis_first2y_2026-07-01.csv](D:/test/ft_userdata/user_data/analysis/raw_short_pullback_touch5_diagnosis_first2y_2026-07-01.csv)

样本概况:

- 先触及 `+5%` 浮盈的交易数: `45`
- 后续最终最大浮盈达到 `+10%` 的强单: `35`
- 未达到 `+10%` 的非强单: `10`

## 可用特征

只使用在“首次触及 `+5%` 当下”已经知道的信息:

- `hours_to_5pct`
- `mae_pct`

其中:

- `hours_to_5pct`: 从开仓到首次达到 `+5%` 浮盈所用时间
- `mae_pct`: 在达到 `+5%` 之前，这笔单最大逆向波动

## 最有价值的候选规则

### 候选 A

规则:

- `hours_to_5pct <= 28`
- `mae_pct <= 1.2`

结果:

- 选中: `20`
- 其中强单: `19`
- 其中非强单: `1`
- 精确率: `95.00%`
- 覆盖率: `54.29%`

解释:

- 这条规则很“干净”
- 命中的单子大多数都是真强单
- 但只覆盖了大约一半强单

### 候选 B

规则:

- `hours_to_5pct <= 24`
- `mae_pct <= 1.2`

结果:

- 选中: `18`
- 其中强单: `17`
- 其中非强单: `1`
- 精确率: `94.44%`
- 覆盖率: `48.57%`

解释:

- 比候选 A 更严格一些
- 精确率仍然很高
- 覆盖率再低一点

### 候选 C

规则:

- `hours_to_5pct <= 24`
- `mae_pct <= 1.0`

结果:

- 选中: `16`
- 其中强单: `15`
- 其中非强单: `1`
- 精确率: `93.75%`
- 覆盖率: `42.86%`

解释:

- 更偏保守
- 很适合做第一版实验

### 候选 D

规则:

- `hours_to_5pct <= 32`
- `mae_pct <= 1.2`

结果:

- 选中: `24`
- 其中强单: `21`
- 其中非强单: `3`
- 精确率: `87.50%`
- 覆盖率: `60.00%`

解释:

- 覆盖更多强单
- 但误放行的非强单也更多

## 路径意义

以候选 A 为例:

- 选中的 `20` 笔里，`19` 笔后来真的能扩展到 `+10%`
- 说明 “快到 5% 且前期回撤小” 的组合，和强趋势延续高度相关

同时看 5m 路径:

- 若在这类单子上到 `+5%` 就立刻保本:
  - `15` 笔先到 `+10%`
  - `3` 笔先被保本扫掉
- 若在这类单子上改成 `+1%` 锁仓:
  - `12` 笔先到 `+10%`
  - `5` 笔先被扫掉
- 若在这类单子上改成 `+2%` 锁仓:
  - `9` 笔先到 `+10%`
  - `8` 笔先被扫掉

这说明:

- 对强单候选来说，保护一旦太紧，收益扩展会明显受损
- 这类单子更适合“放行优先”，而不是“快速锁仓优先”

## 当前判断

如果要进入下一轮真实策略验证，最适合作为 V1 候选的不是全面放松，而是:

1. 只针对 `short_pullback_restart`
2. 只在已经触及 `+5%` 后启用
3. 只对满足强单候选条件的单子放宽退出

## 推荐顺序

### 第一优先

候选 A:

- `hours_to_5pct <= 28`
- `mae_pct <= 1.2`

原因:

- 精确率最高
- 样本数不算太小
- 风格上最像“只放行真强单”

### 第二优先

候选 C:

- `hours_to_5pct <= 24`
- `mae_pct <= 1.0`

原因:

- 更保守
- 更适合先做低风险实验

### 第三优先

候选 D:

- `hours_to_5pct <= 32`
- `mae_pct <= 1.2`

原因:

- 覆盖率更高
- 但误放行会更多

## 结论

可以进入下一轮开发验证。

但方向不是:

- 所有单子统一放宽
- 所有到 `+5%` 的单子统一改保护

而是:

- 只给“快速达到 `+5%` 且前期 MAE 很小”的空头主信号做放行

这比全局放松退出，更符合当前样本表现。
