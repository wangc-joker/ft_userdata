## 4. 脚本实现内容

### 4.1 数据读取

完成：

```text
读取 1H futures feather
读取 4H futures feather
按 symbol 自动匹配文件名
支持 --timerange 过滤
支持缺失文件记录，不让整个审计中断
```

修正：

```text
Freqtrade feather 的 date 原始 dtype 是 datetime64[ms, UTC]。
timerange 过滤后可能变成 datetime64[ns, UTC]。
merge_asof 要求左右 dtype 完全一致。
已在读取时统一转换成 datetime64[ns, UTC]。
```

### 4.2 4H 趋势过滤

完成：

```text
ema50_4h
ema200_4h
trend_up_4h
trend_down_4h
```

规则：

```text
trend_up_4h:
    close_4h > ema50_4h
    ema50_4h > ema200_4h
    ema50_4h > ema50_4h.shift(3)

trend_down_4h:
    close_4h < ema50_4h
    ema50_4h < ema200_4h
    ema50_4h < ema50_4h.shift(3)
```

### 4.3 1H 结构指标

完成：

```text
ATR(14)
volume_ma20
compression_high / compression_low
compression_width
center_up / center_down
pretrend_up / pretrend_down
pullback_seen_long / pullback_seen_short
pullback_intact_long / pullback_intact_short
candle_quality_long / candle_quality_short
stop distance
```

关键防 lookahead 规则：

```text
compression_high = high.shift(1).rolling(12).max()
compression_low = low.shift(1).rolling(12).min()
volume_ma20 = volume.shift(1).rolling(20).mean()
```

当前突破 K 线不参与区间计算。

### 4.4 入场信号

完成四类 entry_tag：

```text
long_compression_breakout
long_pullback_restart
short_compression_breakdown
short_pullback_restart
```

每条信号都会记录：

```text
symbol
pair
date
entry_tag
side
close
initial_stop
risk_pct
compression_width_pct
volume_ratio
body_pct_of_range
close_position
forward_ret_6h
forward_ret_24h
forward_ret_72h
mfe_24h
mae_24h
```

说明：

```text
forward_ret / MFE / MAE 是事后观察指标，只用于判断信号质量。
它不是正式回测收益。
```

### 4.5 BTC 大盘过滤

完成：

```text
默认开启 BTC 4H 方向过滤。
非 BTC 做多时，BTC 4H 不能处于 trend_down_4h。
非 BTC 做空时，BTC 4H 不能处于 trend_up_4h。
```

可用参数关闭：

```text

```
