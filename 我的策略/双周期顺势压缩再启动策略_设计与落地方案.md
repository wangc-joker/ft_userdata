# 双周期顺势压缩再启动策略：设计与落地方案

## 1. 文档目标

本文档用于把一个人工交易思想，转化为可以进一步实现、回测、优化的量化策略描述。

策略核心：

```text
顺大势，也顺小势。
大周期决定交易方向，小周期决定具体入场点。
大周期向上时，只寻找小周期向上的机会做多。
大周期向下时，只寻找小周期向下的机会做空。
入场不追求最低点或最高点，而是等待小周期出现力量重新释放，再顺势进场。
```

第一版目标不是追求最高收益，而是验证以下逻辑是否有效：

```text
4H 趋势过滤
+
1H 压缩突破 / 回调再启动
+
结构止损
+
分批止盈
+
移动止损
+
无补仓
```

## 3. 适用市场与第一版范围

第一版建议用于：

```text

```

方向：

```text

```

不建议第一版直接用于：

```text

极端高波动币种
高杠杆实盘
```

## 4. 周期设计

第一版推荐：

```text
大周期：4H
小周期：1H
```

原因：

```text
4H 用于判断中短期主趋势，能过滤较多噪音。
1H 用于寻找具体入场点，信号数量适中。
相比 5m/15m，1H 假突破更少。
相比 1D/4H，4H/1H 信号更多，便于回测验证。
```

后续可扩展：

```text
稳健版：1D + 4H
活跃版：4H + 1H
短线版：1H + 15m
```

## 6. 总体交易规则

### 6.1 多头总规则

```text
当 4H 大周期处于上涨趋势时，只允许寻找多头机会。
在 1H 小周期上，等待价格出现高位压缩突破，或回调结束后的再启动突破。
当 1H 收盘价有效突破小周期结构上沿，并且成交量确认时，开多。
止损放在突破前结构低点下方。
```

### 6.2 空头总规则

```text
当 4H 大周期处于下跌趋势时，只允许寻找空头机会。
在 1H 小周期上，等待价格出现低位压缩跌破，或反弹结束后的再下跌。
当 1H 收盘价有效跌破小周期结构下沿，并且成交量确认时，开空。
止损放在跌破前结构高点上方。
```

## 8. 大周期趋势判断

### 8.1 4H 上涨趋势

满足以下全部条件：

```text
close_4h > EMA50_4h
EMA50_4h > EMA200_4h
EMA50_4h > EMA50_4h.shift(3)
```

含义：

```text
价格在中期均线上方。
中期均线在长期均线上方。
中期均线正在上行。
```

只有满足该条件，策略才允许做多。

### 8.2 4H 下跌趋势

满足以下全部条件：

```text
close_4h < EMA50_4h
EMA50_4h < EMA200_4h
EMA50_4h < EMA50_4h.shift(3)
```

含义：

```text
价格在中期均线下方。
中期均线在长期均线下方。
中期均线正在下行。
```

只有满足该条件，策略才允许做空。

## 9. 1H 压缩区间定义

### 9.1 压缩观察窗口

```text
compression_window = 12
```

也就是最近 12 根 1H K 线。

### 9.2 区间高低点

```text
compression_high = 最近 12 根 1H K 线最高价
compression_low = 最近 12 根 1H K 线最低价
compression_width = compression_high - compression_low
```

### 9.3 压缩条件

```text
compression_width < ATR_1H * 3
```

含义：

```text
最近 12 小时价格波动范围不能太大。
如果区间太宽，说明压缩不充分，突破风险较大。
```

## 10. 重心上移与重心下移

### 10.1 多头重心上移

把最近 12 根 1H K 线分成前 6 根和后 6 根。

满足：

```text
后 6 根最低价 > 前 6 根最低价
后 6 根收盘均价 > 前 6 根收盘均价
```

程序化表达：

```text
low_min_last_half > low_min_first_half
close_mean_last_half > close_mean_first_half
```

含义：

```text
震荡区间内价格重心逐渐上移。
卖压逐步减弱，买盘逐步占优。
```

### 10.2 空头重心下移

满足：

```text
后 6 根最高价 < 前 6 根最高价
后 6 根收盘均价 < 前 6 根收盘均价
```

程序化表达：

```text
high_max_last_half < high_max_first_half
close_mean_last_half < close_mean_first_half
```

含义：

```text
震荡区间内价格重心逐渐下移。
买盘反弹无力，卖压逐步占优。
```

## 11. 多头入场形态 A：高位压缩突破

### 11.1 形态描述

```text
大周期处于上涨趋势。
小周期此前已经有一段上涨。
上涨后价格没有明显回落，而是在相对高位横盘。
横盘过程中波动范围收窄，低点逐渐抬高，交易重心上移。
当价格向上突破横盘区间上沿时，认为小周期向上力量重新释放，开多。
```

### 11.2 入场条件

满足以下全部条件：

```text
1. 4H 趋势向上
2. 1H 最近 24 根 K 线曾经有明显上涨
3. 最近 12 根 1H K 线形成窄幅震荡区间
4. compression_width < ATR_1H * 3
5. 后 6 根最低价 > 前 6 根最低价
6. 后 6 根收盘均价 > 前 6 根收盘均价
7. 当前 1H close > compression_high
8. 当前 1H volume > volume_ma20 * 1.2
```

### 11.3 止损

```text
stop_price = compression_low - 0.2 * ATR_1H
```

### 11.4 入场标签

```text
long_compression_breakout
```

## 15. 不入场条件

即使出现突破，也要过滤以下情况。

### 15.1 止损距离太大

```text
abs(entry_price - stop_price) / entry_price > 5%
```

如果止损距离超过 5%，说明：

```text
入场太晚
结构太宽
盈亏比不合适
合约风险太大
```

直接放弃交易。

### 15.2 止损距离太小

```text
abs(entry_price - stop_price) / entry_price < 0.5%
```

如果止损太近，容易被正常波动扫损。

### 15.3 成交量不足

```text
current_volume <= volume_ma20 * 1.2
```

低成交量突破不参与。

### 15.4 BTC 大方向冲突

可选过滤：

```text
做多山寨币时，BTC 4H 不应处于明显下跌趋势。
做空山寨币时，BTC 4H 不应处于明显上涨趋势。
```

第一版可以作为可选参数，不强制启用。

### 15.5 最大持仓限制

```text
max_open_trades = 3
```

当前已有 3 个持仓时，不再开新仓。

## 16. 仓位管理

### 16.1 每笔风险

第一版建议：

```text
每笔最大亏损 = 账户权益的 0.75%
risk_per_trade = 0.0075
```

例如：

```text
账户 1000 USDT，每笔最多亏损 7.5 USDT
账户 5000 USDT，每笔最多亏损 37.5 USDT
```

### 16.2 仓位计算

多头：

```text
risk_distance = entry_price - stop_price
position_qty = account_equity * risk_per_trade / risk_distance
position_value = position_qty * entry_price
```

空头：

```text
risk_distance = stop_price - entry_price
position_qty = account_equity * risk_per_trade / risk_distance
position_value = position_qty * entry_price
```

### 16.3 单笔仓位上限

为了防止止损很近时仓位过大：

```text
position_value <= account_equity * 35%
```

参数：

```text
max_position_value_pct = 0.35
```

### 16.4 最大同时持仓

```text
max_open_trades = 3
```

### 16.5 杠杆

第一版建议：

```text
leverage = 1x - 2x
```

不建议第一版使用：

```text
5x
10x
20x
```

## 17. 止盈设计

本策略采用：

```text
分批止盈 + 移动止损
```

### 17.1 R 的定义

多头：

```text
R = entry_price - stop_price
```

空头：

```text
R = stop_price - entry_price
```

### 17.2 多头止盈

```text
TP1 = entry_price + 1R
TP2 = entry_price + 2R
```

规则：

```text
价格达到 TP1：
    止盈 30%
    止损移动到开仓价

价格达到 TP2：
    再止盈 30%

剩余 40%：
    使用 1H 结构移动止损继续持有
```

### 17.3 空头止盈

```text
TP1 = entry_price - 1R
TP2 = entry_price - 2R
```

规则：

```text
价格达到 TP1：
    止盈 30%
    止损移动到开仓价

价格达到 TP2：
    再止盈 30%

剩余 40%：
    使用 1H 结构移动止损继续持有
```

## 18. 移动止损设计

### 18.1 多头移动止损

达到 1R 后：

```text
stop_price = entry_price
```

达到 2R 后，剩余仓位使用结构移动止损：

```text
new_stop = 最近有效 1H swing low - 0.2 * ATR_1H
```

若 new_stop 高于当前止损，则上移止损。

### 18.2 空头移动止损

达到 1R 后：

```text
stop_price = entry_price
```

达到 2R 后，剩余仓位使用结构移动止损：

```text
new_stop = 最近有效 1H swing high + 0.2 * ATR_1H
```

若 new_stop 低于当前止损，则下移止损。

## 19. 补仓规则

第一版明确禁止补仓：

```text
不允许亏损补仓
不允许摊低成本
不允许 DCA
不允许网格式加仓
```

原因：

```text
该策略属于右侧突破策略。
如果突破失败，说明判断错误，应按结构止损退出。
亏损补仓会破坏策略的风险收益结构。
```

### 21.1 基础回测

建议先回测：

```text
2021-01-01 至 当前
```

也可以按年度分段：

```text
2021
2022
2023
2024
2025
2026
```

### 21.2 必看指标

```text
总收益
最大回撤
Profit Factor
胜率
平均盈亏比
最大连续亏损
最大单笔亏损
平均持仓时间
多头收益
空头收益
按币种收益
按 entry_tag 收益
```

### 21.3 第一版验收标准

```text

最大回撤 < 25%
至少 150 笔交易
多头和空头至少一侧有效
至少 3 个币种正收益
不能只靠单个币种赚钱
不能只靠单个 entry_tag 赚钱
```

进一步优化目标：

```text
Profit Factor > 1.5
最大回撤 < 15%-20%
样本外 PF > 1.2
手续费/滑点压力测试后仍为正
```

## 22. 样本外与防过拟合

### 22.1 样本内 / 样本外

示例：

```text
样本内：2021-01-01 至 2024-12-31
样本外：2025-01-01 至 当前
```

要求：

```text
样本外必须为正收益
样本外 PF 不应低于 1.2
样本外回撤不能显著高于样本内
```

### 22.2 Walk-forward

按年度测试：

```text
2021
2022
2023
2024
2025
2026
```

要求：

```text
不能只有某一年大赚，其他年份都亏。
至少大部分年份表现可接受。
```

### 22.3 压力测试

需要测试：

```text
手续费提高 1.5 倍
手续费提高 2 倍
加入 0.05% 滑点
加入 0.10% 滑点
加入 0.20% 滑点
```

如果轻微增加成本后策略立即失效，说明策略边际太薄，不适合实盘。

### 23.1 BTC 大盘过滤

对山寨币做多时：

```text
BTC 4H 不应处于明显下跌趋势。
```

## 26. 总结

本策略的最终定义：

```text
双周期顺势压缩再启动策略，是一种数字货币合约多空趋势策略。

它使用 4H 判断主方向，使用 1H 寻找入场结构。
只有当大周期方向明确时，才允许在小周期寻找同方向机会。

小周期入场基于两种形态：
1. 趋势延续中的压缩突破；
2. 回调或反弹结束后的再启动突破。

策略不追求最低点或最高点，而是等待小周期结构确认后顺势入场。
止损基于突破前结构，仓位基于单笔风险计算。
止盈采用 1R、2R 分批止盈，剩余仓位用结构移动止损跟随趋势。
第一版不允许补仓，不允许亏损加仓。
```
