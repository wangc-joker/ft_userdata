# 双周期顺势压缩再启动策略：完善版方案

## 1. 文档定位

本文档是在原始《双周期顺势压缩再启动策略：设计与落地方案》基础上补全的一版可实现方案。

目标不是继续堆叠旧策略里的复杂模块，而是把一个干净的核心交易思想落成可以编码、回测、验证、实盘前审查的策略规格。

核心原则：

```text
顺大势，也顺小势。
大周期只决定方向，小周期只负责入场。
只做右侧确认，不抄底，不摸顶。
突破前必须有压缩或回调后的再启动结构。
每笔交易在入场时就确定初始止损、R 值、TP1、TP2。
不亏损补仓，不 DCA，不网格。
先验证信号是否有边际，再考虑优化收益。
```

新版主线策略名：

```text
DualTrendCompressionRestartStrategy
```

中文名：

```text
双周期顺势压缩再启动策略
```

旧版 `Top9RegimeStructureStrategy` 只作为参考库，不作为新版继承对象。新版代码应重新写一份干净策略，避免旧实验逻辑继续污染主线。

---

## 2. 第一版实现范围

第一版只实现以下内容：

```text
4H 趋势过滤
1H 压缩突破
1H 回调再启动
结构止损
按风险距离计算仓位
1R / 2R 分批止盈
剩余仓位结构移动止损
基础 protections
BTC 大盘过滤开关
```

第一版不实现：

```text
reversal 反转策略
AI 过滤
复杂 pair 特化参数
recent performance 动态暂停 tag
亏损补仓
多层 stake multiplier
```

可以保留的后续扩展：

```text
1D 大环境过滤
ADX 趋势强度过滤
分币种分组参数
成交额动态 pairlist
实盘滑点保护
```

## 7. 数据使用原则

所有结构区间必须排除当前 K 线。

错误写法：

```text
compression_high = high.rolling(12).max()
```

正确写法：

```text
compression_high = high.shift(1).rolling(12).max()
compression_low = low.shift(1).rolling(12).min()
```

原因：

```text
当前 K 线本身就是突破 K。
如果把当前 K 线计入区间高低点，突破条件会失真。
```

成交量均值也建议排除当前 K 线：

```text
volume_ma20 = volume.shift(1).rolling(20).mean()
```

ATR 用于压缩判断和止损缓冲时，建议使用上一根已完成 K 的 ATR：

```text
atr_ref = atr.shift(1)
```

## 8. 4H 趋势判断

### 8.1 4H 上涨趋势

满足全部条件：

```text
close_4h > ema50_4h
ema50_4h > ema200_4h
ema50_4h > ema50_4h.shift(3)
```

输出：

### 8.2 4H 下跌趋势

满足全部条件：

```text
close_4h < ema50_4h
ema50_4h < ema200_4h
ema50_4h < ema50_4h.shift(3)
```

输出：

```text
trend_down_4h = True
```

### 8.3 无趋势状态

如果既不是上涨趋势，也不是下跌趋势：

```text
trend_neutral_4h = True
```

第一版在无趋势状态不主动开仓。

## 9. 1H 基础指标

需要计算：

```text
atr_1h = ATR(14)
atr_ref = atr_1h.shift(1)
atr_pct = atr_1h / close

volume_ma20 = volume.shift(1).rolling(20).mean()
vol_ok = volume > volume_ma20 * 1.2

compression_high = high.shift(1).rolling(12).max()
compression_low = low.shift(1).rolling(12).min()
compression_width = compression_high - compression_low
compression_width_pct = compression_width / close
compression_ok = compression_width < atr_ref * 3.0
```

突破方向：

```text
breakout_long = close > compression_high * (1 + breakout_buffer)
breakout_short = close < compression_low * (1 - breakout_buffer)
```

## 10. 重心上移与重心下移

当前 K 线不参与重心计算。

最近 12 根已完成 1H K 线分成两半：

```text
前半段 = t-12 到 t-7
后半段 = t-6 到 t-1
```

程序化字段：

```text
low_min_first_half = low.shift(7).rolling(6).min()
low_min_last_half = low.shift(1).rolling(6).min()

high_max_first_half = high.shift(7).rolling(6).max()
high_max_last_half = high.shift(1).rolling(6).max()

close_mean_first_half = close.shift(7).rolling(6).mean()
close_mean_last_half = close.shift(1).rolling(6).mean()
```

多头重心上移：

```text
center_up =
    low_min_last_half > low_min_first_half
    and close_mean_last_half > close_mean_first_half
```

空头重心下移：

```text
center_down =
    high_max_last_half < high_max_first_half
    and close_mean_last_half < close_mean_first_half
```

## 11. 前置趋势定义

压缩突破必须发生在已经有一段同向趋势之后，不能在完全随机震荡中乱做突破。

### 11.1 多头前置上涨

使用最近 24 根已完成 1H K 线：

```text
return_24h = close.shift(1) / close.shift(25) - 1
atr_pct_24h = atr_pct.shift(1).rolling(24).mean()
pretrend_threshold = max(0.02, 1.5 * atr_pct_24h)

pretrend_up = return_24h > pretrend_threshold
```

### 11.2 空头前置下跌

```text
pretrend_down = return_24h < -pretrend_threshold
```

说明：

```text
2% 是最低趋势幅度要求。
1.5 * ATR_pct 是波动率自适应要求。
```

---

## 12. 回调与反弹定义

### 12.1 多头回调

使用最近 24 根已完成 K 线高点和最近 12 根已完成 K 线低点：

```text
recent_high_24 = high.shift(1).rolling(24).max()
pullback_low_12 = low.shift(1).rolling(12).min()
pullback_depth_long = (recent_high_24 - pullback_low_12) / recent_high_24
```

多头回调成立：

```text
pullback_seen_long =
    pullback_depth_long >= 0.008
    and pullback_depth_long <= 0.08
```

回调未破坏 4H 趋势：

```text
pullback_intact_long =
    pullback_low_12 >= ema50_4h * 0.99
```

### 12.2 空头反弹

```text
recent_low_24 = low.shift(1).rolling(24).min()
pullback_high_12 = high.shift(1).rolling(12).max()
pullback_depth_short = (pullback_high_12 - recent_low_24) / recent_low_24
```

空头反弹成立：

```text
pullback_seen_short =
    pullback_depth_short >= 0.008
    and pullback_depth_short <= 0.08
```

反弹未破坏 4H 下跌趋势：

```text
pullback_intact_short =
    pullback_high_12 <= ema50_4h * 1.01
```

说明：

```text
0.8% 以下的回调太浅，可能只是噪音。
8% 以上的回调可能已经破坏短期趋势，第一版先不参与。
```

## 14. 突破 K 线质量过滤

多头突破希望 K 线有实体、有收盘确认，不能长上影假突破。

字段：

```text
candle_range = high - low
body_size = abs(close - open)
body_pct_of_range = body_size / candle_range
close_position = (close - low) / candle_range
```

多头 K 线质量：

```text
candle_quality_long =
    candle_range > 0
    and body_pct_of_range >= 0.35
    and close_position >= 0.60
```

空头 K 线质量：

```text
candle_quality_short =
    candle_range > 0
    and body_pct_of_range >= 0.35
    and close_position <= 0.40
```

说明：

```text
这个过滤不追求完美形态，只过滤明显的假突破和长影线。
```

## 15. 止损距离过滤

入场价：

```text
entry_price = close
```

多头风险距离：

```text
risk_distance = entry_price - initial_stop
risk_distance_pct = risk_distance / entry_price
```

空头风险距离：

```text
risk_distance = initial_stop - entry_price
risk_distance_pct = risk_distance / entry_price
```

允许入场：

```text
min_stop_distance <= risk_distance_pct <= max_stop_distance
```

默认：

```text
0.5% <= risk_distance_pct <= 5%
```

含义：

```text
止损太近，容易被正常波动扫掉。
止损太远，说明入场太晚或结构太宽，盈亏比不合适。
```

## 17. 仓位管理

### 17.1 每笔固定风险

每笔最大亏损：

```text
risk_capital = account_equity * risk_per_trade
```

默认：

```text
risk_per_trade = 0.0075
```

也就是单笔最多亏账户权益的 0.75%。

### 17.2 仓位计算

```text
position_value_by_risk = risk_capital / risk_distance_pct
position_value_cap = account_equity * max_position_value_pct
position_value = min(position_value_by_risk, position_value_cap)
```

默认：

```text
max_position_value_pct = 0.35
```

第一版建议：

```text
leverage = 1.0
```

如果后续使用 2x 杠杆，需要明确区分：

```text
position_notional = margin_stake * leverage
```

为了避免实盘误解，第一版先固定 1x。

### 17.3 不使用多层 multiplier

新版第一版不使用：

```text
signal_multiplier
pair_multiplier
regime_multiplier
recent_performance_multiplier
```

原因：

```text
先验证信号本身是否有效。
如果第一版就加入多层 multiplier，很难判断收益来自信号还是来自调仓。
```

## 18. 止盈与移动止损

### 18.1 R 值定义

多头：

```text
R = entry_price - initial_stop
```

空头：

```text
R = initial_stop - entry_price
```

### 18.2 多头止盈

```text
TP1 = entry_price + 1R
TP2 = entry_price + 2R
```

规则：

```text
到达 TP1：
    平掉原始仓位的 30%
    剩余仓位止损移动到 entry_price

到达 TP2：
    再平掉原始仓位的 30%

剩余 40%：
    使用 1H swing low 结构移动止损
```

### 18.3 空头止盈

```text
TP1 = entry_price - 1R
TP2 = entry_price - 2R
```

规则：

```text
到达 TP1：
    平掉原始仓位的 30%
    剩余仓位止损移动到 entry_price

到达 TP2：
    再平掉原始仓位的 30%

剩余 40%：
    使用 1H swing high 结构移动止损
```

### 18.4 结构移动止损

多头：

```text
swing_stop_long = low.shift(1).rolling(6).min() - 0.2 * atr_ref
new_stop = max(current_stop, swing_stop_long)
```

空头：

```text
swing_stop_short = high.shift(1).rolling(6).max() + 0.2 * atr_ref
new_stop = min(current_stop, swing_stop_short)
```

移动止损只在 TP2 之后启用。TP1 到 TP2 之间只做保本保护。

## 19. Freqtrade 落地细节

### 19.1 入场时需要保存的数据

每笔交易必须保存：

```text
initial_stop
initial_r
tp1_price
tp2_price
tp1_done
tp2_done
current_stop
```

优先实现方式：

```text
使用 Trade custom_data 保存。
```

如果当前 Freqtrade 版本不方便在入场瞬间写入 custom_data，可以用备选方式：

```text
根据 trade.open_date_utc 找到开仓那根 1H K 线，
再按 entry_tag 重新读取当时对应的 stop 列和 R 值。
```

不建议每次用最新 K 线重新计算初始 R。初始 R 必须来自开仓时的结构。

### 19.2 指标列建议

建议在 dataframe 中保留以下列：

```text
long_compression_stop
long_pullback_stop
short_compression_stop
short_pullback_stop

long_compression_risk_pct
long_pullback_risk_pct
short_compression_risk_pct
short_pullback_risk_pct

enter_initial_stop
enter_risk_pct
```

当某个 entry_tag 触发时，把对应 stop 和 risk 写入统一列：

```text
enter_initial_stop
enter_risk_pct
```

这样 `custom_stake_amount` 和后续交易状态初始化更清楚。

### 19.3 custom_stake_amount 数据读取

`custom_stake_amount()` 不能假设自己天然拿得到本次入场的 stop。实现时必须主动读取最新 analyzed dataframe：

```text
dataframe, _ = self.dp.get_analyzed_dataframe(pair, self.timeframe)
candle = dataframe.iloc[-1]
enter_initial_stop = candle["enter_initial_stop"]
enter_risk_pct = candle["enter_risk_pct"]
```

如果出现以下情况，必须拒绝入场或返回 0：

```text
self.dp 不存在
dataframe 为空
enter_initial_stop 缺失
enter_risk_pct 缺失
enter_risk_pct 为 NaN
enter_risk_pct <= 0
enter_risk_pct 超出 min_stop_distance / max_stop_distance
```

原则：

```text
拿不到入场 stop，就不允许开仓。
宁愿少开一笔，也不要在无法计算风险的情况下开仓。
```

不要在 `custom_stake_amount()` 里临时用最新 low/high 粗略猜 stop。入场 stop 必须来自 `populate_entry_trend()` 当根信号写入的 `enter_initial_stop`。

### 19.4 分批止盈实现

使用：

```text
position_adjustment_enable = True
adjust_trade_position()
```

逻辑：

```text
如果未 TP1，且价格达到 TP1：
    返回负数，平掉原始 stake 的 30%
    标记 tp1_done = True

如果已 TP1 且未 TP2，且价格达到 TP2：
    返回负数，平掉原始 stake 的 30%
    标记 tp2_done = True

其他情况：
    return None
```

注意：

```text
adjust_trade_position 只允许减仓，不允许任何加仓。
```

重复触发保护：

```text
TP1 / TP2 每个交易只能触发一次。
每次判断前必须读取 trade custom_data。
触发 TP1 后必须立即写入 tp1_done = True。
触发 TP2 后必须立即写入 tp2_done = True。
如果 custom_data 读取或写入失败，宁愿不减仓，也不要重复减仓。
```

原因：

```text
如果价格连续多根 K 线停在 TP1 或 TP2 上方，
没有 done 标记会导致 adjust_trade_position 反复减仓。
```

### 19.5 custom_stoploss

止损优先级：

```text
1. 初始结构止损
2. TP1 后保本
3. TP2 后结构移动止损
```

多头：

```text
当前 stop = initial_stop
如果 tp1_done：stop = max(stop, entry_price)
如果 tp2_done：stop = max(stop, swing_stop_long)
```

空头：

```text
当前 stop = initial_stop
如果 tp1_done：stop = min(stop, entry_price)
如果 tp2_done：stop = min(stop, swing_stop_short)
```

Freqtrade 返回值注意：

```text
custom_stoploss 内部保存和比较的是 stop_price。
但返回给 Freqtrade 的不能是 stop_price 本身。
必须把 stop_price 转换成相对 current_rate 的止损比例。
多头和空头转换方式不同，必须单独处理。
```

建议实现：

```text
使用 freqtrade.strategy.stoploss_from_absolute(
    stop_price,
    current_rate,
    is_short=trade.is_short,
    leverage=trade.leverage,
)
```

禁止写法：

```text
return stop_price
```

### 19.6 custom_exit

除了止损和分批止盈外，保留时间退出：

```text
持仓 > 72h 且收益 < 0：退出
持仓 > 120h 且收益 < 1%：退出
持仓 > 240h 且收益 < 3%：退出
```

趋势翻转退出：

```text
多头持仓时，如果 4H 转为明确下跌，且当前收益不高于 1R：退出
空头持仓时，如果 4H 转为明确上涨，且当前收益不高于 1R：退出
```

如果已经超过 TP2，优先让结构移动止损管理，不轻易因为小幅趋势波动退出。

## 25. 最终结论

完善版策略的核心定义：

```text
4H 决定方向。
1H 等待压缩、重心变化和突破。
入场只做同方向右侧确认。
初始止损来自突破前结构。
仓位来自单笔风险和止损距离。
盈利后按 R 分批释放风险。
剩余仓位用结构移动止损跟随趋势。
不补仓，不反转，不复杂特化。
```

这版方案的目标不是让回测收益最夸张，而是得到一套：

```text
逻辑清楚
代码干净
风险可解释
容易排查
可以持续迭代
适合实盘前验证
```

的核心双顺策略。
